# IFAC poster resources

Live page: https://wealhour.github.io/IFAC_poster_QRcode/

A mobile-friendly resource page for the poster displayed in the lab after IFAC 2026 in Busan. The existing QR-code destination stays the same.

- `index.html`: page content and responsive styling, with the original HAL and LinkedIn links.
- `assets/ifac-certificate.pdf`: unchanged original certificate.
- `assets/certificate-preview.jpg`: lightweight, responsive preview of the PDF's single page.

The old public CountAPI counter and its client-side owner token have been removed. Private visitor analytics will be connected once the owner creates a GoatCounter account. No visitor counter is displayed on the page.
